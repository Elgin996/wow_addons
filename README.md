# MRP 档案翻译

**简体中文** | [English](README.en.md)

把其他玩家的 [MyRolePlay](https://www.curseforge.com/wow/addons/my-role-play)（MRP）角色扮演档案翻译成简体中文显示，同时汉化 MyRolePlay 的界面。

> **状态：早期版本。** 已经在游戏里用真实的 Gemini 接口翻译过档案，后台翻译和一次粘贴多份档案都跑通了。新加的提示条、F1–F3 快捷键还在试用中。遇到问题欢迎反馈。

## 为什么需要剪贴板助手

魔兽世界的插件运行在沙盒里，不能联网，不能读写任意文件，也不能往剪贴板里写东西，所以单靠插件没法调用翻译服务。本项目加了一个桌面小程序，用**剪贴板**在游戏和翻译接口之间传递内容：

```
[游戏] 打开档案，按 F1（或点「翻译」）：插件把原文打包，放进已全选的输入框
   │  ① 你按 F2（或 Ctrl+C）—— 提示条自动收起，可以接着做别的、翻别的档案
   ▼
[桌面] 剪贴板助手在后台排队翻译 ── ② 调用 Gemini 或 OpenRouter
   │  ③ 翻好一份就把「所有已翻好的译文」写回剪贴板，并响一声提示音
   ▼
[游戏] ④ 随时打开其中任意一份档案，按 F1（或点「粘贴」），再按 F3（或 Ctrl+V）
         → 翻好的档案一次全部显示中文
```

复制和粘贴必须由你来按：插件写不了剪贴板，只能把文字选中，等你按 Ctrl+C。助手不读写游戏进程。唯一和按键有关的是可选的 **F2 / F3 单键映射**：魔兽窗口在前台时，助手把你按下的 F2 / F3 换成 Ctrl+C / Ctrl+V，一次按键只换成一次按键，和改键软件一样；不想要可以在 `config.json` 里关掉，照常按 Ctrl+C / Ctrl+V。

助手只处理以 `<<MRPTR1 REQ>>` 开头的剪贴板内容，你复制的其他东西一概不读，也不会发送到任何地方；你在等待期间复制了别的东西，助手也不会覆盖它。

## 功能

- **档案窗口**：翻译头衔、当前状态、场外信息、眼睛、身高、体型、外貌描述、年龄、居住地、出生地、格言、背景故事、一眼印象，以及自定义性格特质的名称。颜色、链接、图标、图片和 MRP 排版标签在翻译时会受到保护，翻译完原样还原。
- **不用在游戏里干等**：按完复制就可以走开。助手在后台一份份翻，翻好的译文保留 1 小时；之后粘贴一次，这期间翻好的所有档案一起写入。
- **单键操作**：档案窗口开着时 F1 = 「翻译 / 粘贴」按钮；F2 / F3 = 复制 / 粘贴。
- **鼠标提示和一眼印象预览框**也会显示已有的译文。
- **鼠标提示批量队列**：鼠标扫过的人会自动排进队列，一次复制、一次粘贴就能翻完一批。
- **按原文哈希缓存译文**：档案没改过，下次打开直接显示中文；对方改了哪个字段，就只需重新翻译哪个字段。
- **一键切换**原文和译文。
- **人名**第一次出现时写成「译名（原文）」，例如「艾拉莉亚（Elaria）」；多段的名字逐段译出，有字面意思的姓氏按国服惯例意译（如 Hawkstride → 鹰行者）。魔兽世界的地名、种族、官方人物等使用国服官方译名，提示词里附了一份常用官方译名表。
- **人名对照表**（`names.json`）：让同一个名字在不同档案里的译法保持一致，你也可以手动编辑，指定想要的译法。
- **MyRolePlay 界面汉化**（约 470 条，只在中文客户端生效）。MRP 本身只有英文和法文界面。身高、体重单位会一次性改为厘米、公斤，可以在 MRP 设置里改回。
- 顺带修复了 MRP 截断鼠标提示长文本时会把汉字切成乱码的问题。

## 运行环境

- 魔兽世界，并已安装 [MyRolePlay](https://www.curseforge.com/wow/addons/my-role-play)。TOC 里列出的客户端版本与 MyRolePlay 相同。界面汉化只在中文（zhCN）客户端生效。
- Windows（助手使用 Windows 剪贴板接口）。
- Python 3.10 或更高版本（在 3.14 上开发和测试）。只用标准库，不需要 `pip install`。
- 以下任一接口的 API key：
  - **Google Gemini**（[Google AI Studio](https://aistudio.google.com/)）。默认模型：`gemini-3.5-flash-lite`，思考等级 `low`，一份档案通常 2–8 秒。想要更稳的译名，可以换成 `gemini-3.8-flash`（同样设 `low`，大约慢一倍）。
  - **OpenRouter**（[openrouter.ai](https://openrouter.ai/)）。默认模型：`google/gemini-3.8-flash`，也可以换成 OpenRouter 上的任何模型。

## 安装

1. 把 `MRP_Translate` 文件夹复制到 `World of Warcraft\_retail_\Interface\AddOns\`。
2. `MRP_Translate_Helper` 放在任意位置，不需要放进游戏目录。
3. 把 API key 设成环境变量，然后**新开**一个命令行窗口（`setx` 只对新窗口生效）：
   ```
   setx GEMINI_API_KEY "你的key"
   ```
   使用 OpenRouter 的话，改设 `OPENROUTER_API_KEY`，并把 `config.json` 里的 `provider` 改成 `"openrouter"`。
4. 检查 key 和模型是否可用：
   ```
   python mrptr_helper.py --check
   ```

## 使用

1. 启动助手：双击 `启动助手.bat`，或运行 `python mrptr_helper.py`。窗口标题会显示当前状态（翻译中、有几人的译文待粘贴）。
2. 在游戏里打开别人的 MRP 档案，按 **F1**，或点档案窗口底部标签页右边的「**翻译**」。按钮下方会出现一条提示。
3. 按 **F2**（或 Ctrl+C）。提示条自动收起，聊天框提示「已发给助手」。接下来可以去做别的，也可以接着翻别的档案。
4. 助手每翻好一份就响一声。随时打开其中任意一份档案，这时按钮显示「**粘贴**」：按 **F1**（或点「粘贴」），再按 **F3**（或 Ctrl+V）。这期间翻好的所有档案一次全部写入，之后打开其他几份也直接是中文。

提示条出现后按 Esc 或任何普通按键（比如走路）都会收起它，把键盘还给游戏。

「**原文 / 中文**」按钮可以随时切换显示，鼠标提示和一眼印象预览框会一起切换。

**F1–F3 的说明**

- F1 只在档案窗口开着时才是「翻译 / 粘贴」，关掉窗口后恢复原来的功能（默认是选中自己）。战斗中不能改键位，所以战斗里打开的档案要等脱战后 F1 才生效。想换键，改 `UI.lua` 开头附近的 `HOTKEY`。
- F2 / F3 只在助手运行、且魔兽窗口在前台时生效，这时它们原来的功能（默认是选中队友）用不了；切到别的程序完全不受影响。想换键或关掉，改 `config.json` 里的 `hotkeys`（支持 F1–F24，留空即关闭）。

**如果你在等待期间复制了别的东西**，剪贴板里就不是译文了，助手不会覆盖它。这时在游戏里按 F1 → F2 再发一次：译文已经在缓存里，马上就会响；再按 F1 → F3 粘贴即可。

**批量翻译鼠标提示**：鼠标提示没法停下来复制，所以扫过的人会自动排进队列，攒到 5 人时聊天框会提示一次。之后可以：

- 在「按键设置 → 插件 → MRP 档案翻译 → 翻译鼠标提示队列」里设一个快捷键，或者
- 输入 `/mrptr queue`。

打开队列后按 F2 发出整批；听到提示音后再打开一次队列（或打开其中任意一份档案按 F1），按 F3 粘贴。

| 命令 | 作用 |
|---|---|
| `/mrptr` | 查看缓存和队列状态 |
| `/mrptr queue` | 翻译鼠标提示队列 |
| `/mrptr clear` | 清空所有译文缓存 |

**建议**：第一次使用时，先把 `config.json` 里的 `provider` 设成 `"test"`。这样助手不调用任何接口，只在原文前加一个标记，可以免费跑通游戏里的整个流程。

## 配置

以下文件都在 `MRP_Translate_Helper/` 里。改完要重启助手才生效。

| 文件 | 用途 |
|---|---|
| `config.json` | `provider`（`gemini`、`openrouter` 或 `test`）、模型名、`thinking_level`（Gemini 的思考等级，默认 `low`；留空则由模型自己决定，同一份档案可能要等一分多钟）、`timeout_seconds`（超时秒数）、`beep`（是否响提示音）、`hotkeys`（单键复制粘贴，默认 `F2` / `F3`，留空关闭）。`api_key` 也可以写在这里，但更推荐用环境变量。 |
| `prompt.txt` | 发给模型的翻译要求和官方译名表，可以随意修改。 |
| `names.json` | 人名对照表，自动生成。已有的条目不会被模型覆盖，你手动改过的译法会一直保留。 |
| `cache.json` | 译文缓存，自动生成，最多保留 5000 条。删掉它就会全部重新翻译（游戏里也要输入 `/mrptr clear`）。 |

## 费用

按 Gemini 3.8 Flash 的付费价格计算（每百万 token 输入 $0.75、输出 $3.75，2026 年 12 月 31 日之前有效，2027 年 1 月 1 日起翻倍），一份普通档案大约 **$0.01**。默认的 Flash-Lite 单价更低，具体以服务商的价格页面为准。提示词里带了一份官方译名表，每次请求会多出约 3000 个输入 token。缓存过的档案不再收费。

## 隐私

- **其他玩家**写的档案内容会发送给你选择的翻译服务商。
- Gemini 免费版会用提交的内容改进 Google 的产品，付费版不会。
- 助手只处理以请求标记开头的剪贴板内容，你复制的其他东西不会被读取，也不会被发送。
- F2 / F3 单键映射用的是 Windows 键盘钩子：只认 F2、F3 这两个键，并且只在魔兽窗口在前台时才处理，其他按键原样放行，不记录、不发送。
- **这个仓库是公开的**，千万不要把 API key 写在 `config.json` 里提交，请用环境变量。

### 译文是怎么显示出来的

MRP 绘制档案窗口、鼠标提示、一眼印象预览框之前，插件先把这个人的字段临时换成缓存里的译文，画完立刻换回原文。这样 MRP 自己的排版、单位换算、一眼印象和性格特质的解析都照常工作，**MyRolePlay 的文件一个都不用改**。万一出错，MRP 会照常显示原文，聊天框只提示一次。

### 剪贴板协议（`MRPTR1`）

```
<<MRPTR1 REQ>>
@player 名字-服务器
@name 角色名
@field DE 0123456789abcdef
正文，格式标记已替换成 {{1}}、{{2}} …… 占位符
@player 另一个名字-服务器
……
<<MRPTR1 END>>
```

- 回包以 `<<MRPTR1 RES>>` 开头，结构相同；没翻成的字段用 `@failed 字段 原因` 标出。
- 回包里是助手 1 小时内翻好的所有译文（待取池），不只是最近这一份。插件遇到之前已经写入过的同一段译文会直接跳过。
- 出错时回 `<<MRPTR1 ERR>> 原因`。只有待取池是空的时候才会写报错，免得把别人的译文顶掉。
- 正文里以 `@` 或 `<` 开头的行，会在前面再补一个 `@` 来转义。
- 16 位哈希对应原文的确切内容。字段被改过之后，旧译文不会再显示。

## 已知限制

- 只支持 Windows。
- 待取池只存在内存里，重启助手就清空了。已翻好的档案还在缓存里，重发一次（F1 → F2）就能马上拿回来。
- MyRolePlay 代码里有少数英文是直接写死的（不在它的语言表里），不改 MRP 就没法汉化。
- Haranir 等新种族的名称还没有汉化，会显示英文。
